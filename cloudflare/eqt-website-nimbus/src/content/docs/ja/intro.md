# EQT ドキュメントセンターへようこそ

EQT (Easy QR Transfer) は、**第一原理（First Principles）**に基づいてゼロから設計された、クロスプラットフォーム・ローカルネットワーク（LAN）超高速直接転送およびリアルタイムコラボレーションシステムです。

日常的なデータ転送において、集中型クラウドストレージやメッセージングアプリを使用すると、データ漏洩、プライベート写真の無断スキャン、アップロード帯域制限、画質や動画の圧縮といった問題が避けられません。EQT はこれらの問題を根本から解決し、同一 LAN 内の複数デバイス間で直接、安全かつ高速にデータをやり取りする環境を提供します。

---

## コア設計原則

- **物理配線速度の直接通信（Zero Cloud Relay）**：
  送信元と受信先の間でダイレクトなローカルソケット接続を確立します。クラウドサーバーを一切経由せず、ルーターやスイッチの最大物理回線速度でデータを送受信します。
- **モバイルアプリのインストール不要（Zero App Needed）**：
  受信側のスマートフォン（iOS / Android）は、標準のカメラアプリで QR コードをスキャンするだけで即座にブラウザ経由でファイルを受信・送信できます。
- **真の LAN-TLS 暗号化（WebPKI Green Lock）**：
  Let's Encrypt とステートレス数学ループバック DNS を組み合わせ、ローカル転送でありながらブラウザの警告を一切出さず、公式の「緑の南京錠（🔒）」による暗号化接続を実現します。
- **メモリ上のリアルタイムストリーミング ZIP 圧縮**：
  大量のファイルやディレクトリ全体を送信する際、ディスクに一時アーカイブファイルを作成することなく、メモリ上で動的に ZIP ストリームを生成してネットワークに送信します。
