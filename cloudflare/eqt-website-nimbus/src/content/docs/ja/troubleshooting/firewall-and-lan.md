# ファイアウォールと LAN 接続のトラブルシューティング

QR コードをスキャンした後にブラウザで「接続できません」または「タイムアウト」が発生する場合、原因の多くはルーターのプライバシー設定または PC のファイアウォールにあります。

---

## 1. AP 分离 (クライアント分離) の確認

カフェ、ホテル、一部の家庭用ルーターの「ゲスト Wi-Fi」では、セキュリティ機能として **AP 分離（Client Isolation）** が有効になっている場合があります。
この機能が有効だと、同一 Wi-Fi に接続している機器同士の通信が遮断されます。

- **解決方法**：ルーターの管理画面で「AP 分離」「クライアント分離」「プライバシーセパレーター」をオフにするか、メインの通常 Wi-Fi ネットワークに接続してください。

---

## 2. Windows Defender ファイアウォールの許可

Windows 版 EQT の初回起動時に「Windows セキュリティの重要な警告」が表示された場合、「プライベート ネットワーク」にチェックを入れてアクセスを許可する必要があります。

誤ってキャンセルした場合の修復手順：
1. **Windows の設定** ➔ **プライバシーとセキュリティ** ➔ **Windows セキュリティ** ➔ **ファイアウォールとネットワーク保護** を開きます。
2. **ファイアウォールによるアプリケーションの許可** をクリックします。
3. リスト内の `EQT` を探し、「プライベート」のチェックボックスをオンにします。

---

## 3. macOS のローカルネットワーク許可

macOS Sequoia (15.0) 以降では、アプリがローカルネットワーク上の他のデバイスを検出・通信する際にユーザーの明示的な許可が必要です。

1. **システム設定** ➔ **プライバシーとセキュリティ** ➔ **ローカルネットワーク** を開きます。
2. `EQT` のトグルスイッチをオンにします。
