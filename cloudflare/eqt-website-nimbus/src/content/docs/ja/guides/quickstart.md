# クイックスタートガイド

EQT は、PC とモバイルデバイス間で最もスムーズなファイル共有体験を提供します。追加のアプリインストールやアカウント作成は一切不要です。

---

## 1. ファイルを送信する（PC ➔ スマホ）

1. **EQT を起動**：Windows、macOS、または Linux デスクトップで EQT アプリケーションを起動します。
2. **ファイルをドラッグ＆ドロップ**：
   - 送信したいファイルやフォルダを直接 EQT のウィンドウにドラッグします。
   - クリップボードにコピーされたテキストやスクリーンショットもワンクリックで共有可能です。
3. **QR コードをスキャン**：
   - スマートフォンの標準**カメラ**アプリを起動し、デスクトップ画面に表示された QR コードをスキャンします。
   - 表示されたリンクをタップすると、Safari または Chrome で安全なダウンロードポータルが開きます。
4. **一括ダウンロード**：
   - フォルダや複数ファイルは、自動的にメモリ上で ZIP アーカイブにまとめられ、1タップで保存できます。

---

## 2. ファイルを受信する（スマホ ➔ PC）

1. **受信モードに切り替え**：EQT デスクトップ画面で「受信」タブを選択します。
2. **QR コードをスキャン**：スマートフォンで受信専用の QR コードをスキャンします。
3. **ファイルをアップロード**：ブラウザから写真、動画、ドキュメントを選択して送信します。
4. **PC に自動保存**：送信されたファイルは、PC の「ダウンロード」フォルダに即座に直接書き込まれます。

---

## 3. 推奨環境

- **ネットワーク**：PC とスマートフォンが同じ Wi-Fi ネットワークまたは同一ローカル LAN に接続されていること。
- **ブラウザ**：
  - iOS：iOS 14 以降の標準 Safari。
  - Android：Chrome、Edge、またはシステム標準ブラウザ。
