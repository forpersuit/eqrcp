# Free 版と Plus 版の機能比較

EQT は、個人利用および日常的なファイル転送に十分な機能を無料で提供しています。さらに高度な機能や複数デバイスでの業務活用を求めるプロフェッショナルのために、Plus ライセンスを用意しています。

---

## 機能比較表

| 機能項目 | Free 版 | Plus 版 |
| :--- | :---: | :---: |
| **ローカル直接転送速度** | 物理回線速度（無制限） | 物理回线速度（無制限） |
| **クラウド中継ゼロ・完全プライベート** | ✅ | ✅ |
| **スマホ側アプリ不要** | ✅ | ✅ |
| **Let's Encrypt LAN-TLS 🔒** | ✅ | ✅ |
| **フォルダの一括 ZIP 送信** | ✅ | ✅ |
| **クリップボード・テキスト共有** | ✅ | ✅ |
| **同時転送セッション** | 標準制限あり | 無制限 |
| **LAN コラボレーション (Chat モード)** | 基本機能 | フル機能・無制限デバイス |
| **ポート固定・バックグラウンドデーモン** | 基本設定 | 完全カスタマイズ可能 |
| **商用利用ライセンス** | 個人利用のみ | 商用利用ライセンス付属 |
| **優先テクニカルサポート** | コミュニティ対応 | 公式メール優先サポート |

---

## ライセンスの移行と管理

Plus ライセンスは、公式のセルフサービスポータルからいつでも管理できます。
新しい PC に買い替えた場合でも、ポータルから古い端末の紐付けを解除するだけで、新しい端末に簡単にライセンスを移行できます。
