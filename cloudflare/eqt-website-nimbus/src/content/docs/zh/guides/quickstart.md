# 快速入门指南

EQT 支持图形界面（GUI）与终端命令行（CLI）两种使用方式。只需电脑与手机连接在同一个局域网（同一 Wi-Fi 或热点）即可。

---

## 模式一：Share 模式（电脑发送 ➔ 手机接收）

当你需要把电脑上的电影、安装包、工作表格或高清图片发送到移动端时使用：

### 1. 桌面端操作
- **GUI 界面**：直接将文件或文件夹拖拽进 EQT 软件窗口，点击“开始发送”。
- **CLI 命令行**：
  ```bash
  # 发送单个文件
  eqt MyDocument.pdf

  # 发送多个文件或整个目录（自动流式 Zip 打包）
  eqt Photos/ Video.mp4
  ```

### 2. 移动端扫码
终端或窗口将显示一张专属二维码以及局域网直连网址。
1. 使用手机原生相机（iOS 相机或 Android 扫一扫）对准二维码。
2. 轻点弹出的网址气泡，浏览器即可打开下载页面。
3. 点击“下载全部”或单独勾选需要的项目进行保存。

---

## 模式二：Receive 模式（手机发送 ➔ 电脑接收）

当你需要将手机相册里的大量视频、照片或本地各类工作文档与媒体资料传输给电脑备份时使用：

### 1. 桌面端启动接收监听
- **GUI 界面**：点击主面板上的“接收文件”标签，或在托盘菜单选择“等待接收”。
- **CLI 命令行**：
  ```bash
  eqt receive
  ```

### 2. 移动端扫码并选取文件
1. 手机相机扫描弹出的二维码打开接收门户。
2. 点击界面上的“选择文件”或“拍照/相册”。
3. 选取你需要上传的文件后，点击“立即发送”。
4. 电脑端将以局域网物理最大带宽极速接收，文件默认存放在系统的“下载”目录中。

---

## 常见操作技巧

- **整目录打包下载**：若发送的是整个目录，EQT 后端采用内存级流式 Zip 压缩技术，无需预先等待漫长的打包过程，扫码后边压缩边传输。
- **自定义端口与网卡**：如果电脑有多个网卡（如无线网卡与虚拟网卡），可通过交互向导选择绑定正确的 Wi-Fi 网卡：
  ```bash
  eqt config
  ```
