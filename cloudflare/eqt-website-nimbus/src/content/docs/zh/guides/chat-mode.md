# 局域网 Chat 协同模式

日常办公中，我们经常遇到需要在手机和电脑之间快速同步一段文本的场景：
- 电脑上查到的一串长收货地址或验证码需要即时同步到移动设备；
- 手机上复制的账号密码、API Token 需要快速发到电脑终端；
- 传统即时通讯软件往往会压缩原图画质，甚至将敏感文本上传到云端服务器。

EQT 的 **Chat 模式** 专为该场景而生：在局域网内建立轻量级即时聊天室，免装应用、即开即用、会话结束阅后即焚。

---

## 启动 Chat 模式

### 1. 桌面端启动
在桌面端点击“局域网 Chat”按钮，或在终端输入：
```bash
eqt chat --browser
```
电脑端会自动打开管理窗口，并生成手机扫码入口。

### 2. 移动端扫码连入
手机扫码即可直接进入 Web 版聊天界面，不需要登录账号，也不需要注册个人信息。

---

## 核心功能特性

### 1. 双向剪贴板即时同步
- 手机端长按复制文本，粘贴到输入框发送后，电脑端窗口会同步展示并支持一键“点击复制”。
- 支持发送多行代码、Markdown 文本及超长链接。

### 2. 多文件与富媒体附件混排
- 可以在聊天过程中随时点击“发送附件”按钮，添加手机相册中的原画质照片、视频或文档。
- 附件通过局域网双向并发通道直传，零画质压缩。

### 3. 主机端连接管控
- 桌面端作为 Host 主机，可实时查看当前局域网内所有在线的设备列表。
- 支持在桌面端一键强制踢出某个异常设备，保障局域网数据安全。

### 4. 阅后即焚与隐私安全
- 关闭聊天窗口或退出命令行后，内存中的即时聊天会话立即被销毁，不在硬盘中留下未加密的明文历史数据库。

### 5. 传输配额与沟通自由
- **文字与剪贴板**：永久免费畅聊，零时长限制与频次拦截。
- **多媒体附件传输**：免费版每日享有 5 分钟（300秒）全速大附件传输体验；配额用尽后进入安全降级通道（单文件上限 4MB，限速 100KB/s），纯文字沟通不受任何影响。升级 Plus 即可解锁全天候无限速、无上限文件直传。
