# 局域网连通性与防火墙排查

扫码后如果手机提示“无法连接到服务器”、“ERR_CONNECTION_TIMED_OUT”或网页一直转圈打不开，95% 以上的原因是**Windows 防火墙拦截**或**路由器开启了 AP 隔离**。

请按照以下顺序逐步排查：

---

## 排查一：确认设备处于同一局域网

1. 确认电脑与手机连接的是**同一个 Wi-Fi 名称（SSID）**。
2. 注意 2.4G 与 5G 频段的区别：大部分路由器允许双频互通，但部分老旧路由器在 2.4G 和 5G 之间存在隔离策略，建议连接相同频段。
3. 如果电脑是通过有线网线连接路由器，手机连接路由器的 Wi-Fi，通常也可以互通，但请确保电脑的有线 IP 与手机的无线 IP 属于同一网段（例如均为 `192.168.1.x`）。

---

## 排查二：Windows 防火墙设置（最常见原因）

Windows 系统默认对未知的局域网入站连接实施严格拦截。

### 1. 检查网络类型为“专用网络”
- 打开 Windows “设置” ➔ “网络和 Internet” ➔ “属性”。
- 确保当前网络配置文件类型为 **“专用网络”（Private Network）**，而非“公用网络”。公用网络会默认拒绝绝大部分局域网入站请求。

### 2. 允许 EQT 通过防火墙
1. 按 `Win + R` 键，输入 `firewall.cpl` 并回车，打开 Windows Defender 防火墙。
2. 点击左侧导航栏的 **“允许应用或功能通过 Windows Defender 防火墙”**。
3. 点击右上角的 **“更改设置”** 按钮。
4. 在列表中找到 **EQT**（或 `eqt.exe`），确保**“专用”**与**“公用”**两栏的复选框均已被勾选。
5. 点击“确定”保存。

---

## 排查三：路由器开启了 AP 隔离（访客 Wi-Fi）

在企业办公室、酒店、咖啡馆或开启了“访客网络”的家庭路由器中，通常开启了 **AP 隔离（Client Isolation）** 功能：
- **表现**：手机和电脑都能上网，但彼此之间无法 Ping 通或建立 TCP 连接。
- **解决方法**：
  - 进入路由器管理后台，在无线高级设置中关闭“AP 隔离”或“客户端隔离”；
  - 或者在无网络互通权限的公共场合，使用手机开启“个人热点”，将电脑连入手机热点进行传输（此方式不仅不受路由器限制，传输速度也极快）。

---

## 排查四：多网卡与虚拟网卡干扰

如果你的电脑安装了虚拟机（VMware / VirtualBox）、Docker 或 VPN 软件，电脑上会存在多个虚拟网卡。EQT 可能会误绑定到虚拟网卡的内网 IP 上。

**解决方法**：
使用配置向导指定物理无线网卡：
```bash
eqt config
```
在提示的网卡列表中，选择你的真实无线网卡（通常标有 `Wi-Fi`、`WLAN` 或 `192.168.x.x` 地址）。
