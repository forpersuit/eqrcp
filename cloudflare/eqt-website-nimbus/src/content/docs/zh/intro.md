# 欢迎使用 EQT

**EQT** 是一款专注于**安全、私密、极速**的跨平台局域网传输与交互工具。它无需在手机或平板端安装任何额外应用，只需打开原生相机扫一扫二维码，即可在电脑与移动设备之间建立高速加密连接。

---

## 核心技术优势

- ⚡ **物理硬件级线速直传**：纯局域网点对点 Socket 直连，无云端服务器中转与带宽限速，传输吞吐从机制上完全释放路由器、无线协议与设备硬件的最大潜能。
- 🔒 **严格零数据上云**：您的照片、视频、敏感工作文档与聊天内容 100% 停留在您的家庭或办公局域网内，0 字节泄露。
- 📱 **移动端零门槛**：iPhone、iPad、Android 手机或平板无需下载任何 App，使用系统自带相机或浏览器扫码即开。
- 🛡️ **基于 Let's Encrypt 的原生 WebPKI 绿锁**：创新研发的 LAN-TLS 无状态回环架构，通过权威公信机构 Let's Encrypt 自动置备专属证书，彻底解决移动端大文件传输内存溢出（OOM）缺陷，单机私钥零泄漏抗局域网嗅探。
- 💬 **全功能局域网 Chat 协同**：内置即时通讯能力，跨端粘贴长文本、代码片段、API Token 与临时截图，支持会话结束后阅后即焚。
