# Welcome to EQT

**EQT** is a cross-platform local area network (LAN) file transfer and collaboration tool built on the principles of **security, absolute privacy, and maximum wire-speed performance**. It requires no app installation on mobile devices—simply scan a QR code with the native camera to establish a high-speed, end-to-end encrypted connection between desktop and mobile devices.

---

## Core Technical Advantages

- ⚡ **Physical Hardware Wire-Speed Streaming**: Direct local P2P socket streaming without cloud relays or artificial bandwidth throttling. The architecture mechanism fully saturates the maximum potential of your local network, wireless protocols, and hardware storage controllers.
- 🔒 **Strict Zero Cloud Storage (Zero Cloud Relay)**: Your photos, 4K videos, confidential documents, and chat messages stay 100% within your home or office local network. Zero bytes touch external cloud servers.
- 📱 **Zero-Friction Mobile Experience**: No apps or third-party clients required on iPhone, iPad, or Android devices. Instant access via the native camera or system browser.
- 🛡️ **WebPKI Green Lock Powered by Let's Encrypt**: An innovative LAN-TLS stateless loopback architecture automatically provisions dedicated device certificates via Let's Encrypt. This prevents iOS WebKit large-file out-of-memory (OOM) crashes and provides complete cryptographic protection against LAN sniffing with zero private key leakage.
- 💬 **Full-Featured LAN Chat Collaboration**: Built-in ephemeral messaging to synchronize cross-device clipboards, code snippets, API tokens, and temporary screenshots with automatic RAM cleanup upon session termination.
