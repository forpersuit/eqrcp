# Free vs Plus 버전 비교

EQT는 개인 및 일상적인 파일 전송에 충분한 기능을 무료로 제공합니다. 다중 기기 환경이나 비즈니스 워크플로우를 위한 추가 기능이 필요한 전문가를 위해 Plus 라이선스를 제공합니다.

---

## 기능 비교표

| 기능 | Free 버전 | Plus 버전 |
| :--- | :---: | :---: |
| **로컬 직접 전송 속도** | 물리 회선 한계 속도 (무제한) | 물리 회선 한계 속도 (무제한) |
| **클라우드 중계 제로・프라이버시 보호** | ✅ | ✅ |
| **모바일 앱 설치 불필요** | ✅ | ✅ |
| **Let's Encrypt LAN-TLS 🔒** | ✅ | ✅ |
| **폴더 일괄 ZIP 패키징 전송** | ✅ | ✅ |
| **클립보드 및 텍스트 즉시 공유** | ✅ | ✅ |
| **동시 전송 세션** | 기본 세션 제한 | 무제한 동시 연결 |
| **LAN 협업 (Chat 모드)** | 기본 기능 | 다중 참여자 무제한 |
| **포트 고정 및 백그라운드 데몬** | 기본 설정 | 완벽한 커스텀 지원 |
| **상업적 이용 라이선스** | 개인 비상업적 용도 | 상업적 이용 가능 라이선스 |
| **기술 지원** | 커뮤니티 지원 | 공식 이메일 우선 지원 |

---

## 라이선스 이전 및 관리

Plus 라이선스는 공식 셀프서비스 포털에서 언제든지 간편하게 관리할 수 있습니다.
새 컴퓨터로 교체한 경우, 포털에서 기존 기기 연결을 해제하고 새 컴퓨터에 라이선스 키를 입력하면 즉시 이전됩니다.
