# 빠른 시작 가이드

EQT는 PC와 스마트폰 간에 가장 직관적인 파일 공유 경험을 제공합니다. 별도의 앱 설치나 회원 가입이 전혀 필요하지 않습니다.

---

## 1. 파일 보내기 (PC ➔ 스마트폰)

1. **EQT 실행**: Windows, macOS 또는 Linux 환경에서 EQT 데스크톱 프로그램을 실행합니다.
2. **파일 드래그 앤 드롭**:
   - 공유하려는 파일이나 폴더를 EQT 창에 끌어다 놓습니다.
   - 클립보드에 복사된 텍스트나 스크린샷도 클릭 한 번으로 공유할 수 있습니다.
3. **QR 코드 스캔**:
   - 스마트폰의 기본 **카메라** 앱을 열고 데스크톱 화면의 QR 코드를 비춥니다.
   - 나타나는 노란색 링크 배너를 탭하면 Safari 또는 Chrome 브라우저에서 안전한 다운로드 페이지가 열립니다.
4. **일괄 다운로드**:
   - 폴더나 다중 파일은 메모리에서 자동으로 ZIP 아카이브로 묶여 탭 한 번으로 바로 저장됩니다.

---

## 2. 파일 받기 (스마트폰 ➔ PC)

1. **수신 모드 전환**: EQT 데스크톱 프로그램에서 "수신" 탭을 선택합니다.
2. **QR 코드 스캔**: 스마트폰 기본 카메라로 수신 전용 QR 코드를 스캔합니다.
3. **파일 업로드**: 열린 브라우저에서 사진, 동영상, 문서를 선택하여 전송합니다.
4. **PC 자동 저장**: 수신된 파일은 컴퓨터의 "다운로드" 폴더에 즉시 저장됩니다.

---

## 3. 권장 환경

- **네트워크**: PC와 스마트폰이 동일한 Wi-Fi 네트워크 또는 동일한 로컬 LAN에 연결되어 있어야 합니다.
- **브라우저**:
  - iOS: iOS 14 이상의 기본 Safari.
  - Android: Chrome, Edge 또는 시스템 기본 웹 브라우저.
