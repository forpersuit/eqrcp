# LAN 협업 (Chat 모드)

EQT의 Chat 모드는 회의실, 임시 프로젝트 팀, 사무실 내부 구성원 간에 계정 없이 안전하게 메모와 파일을 실시간으로 교환할 수 있는 작업 공간을 제공합니다.

---

## 주요 기능

- **계정 및 로그인 제로**: 호스트 PC가 방을 생성하고 참여자는 QR 코드를 스캔하기만 하면 즉시 참여할 수 있습니다.
- **순수 메모리 기반 (RAM 휘발성 보관)**: 모든 채팅 메시지와 텍스트 공유는 호스트 PC의 메모리(RAM) 상에서만 유지되며, 세션 종료 시 디스크에 어떠한 흔적도 남기지 않고 즉시 소멸합니다.
- **무제한 직접 파일 전송**: 대화창을 통한 첨부 파일 전송은 브라우저와 PC 간의 직접 소켓 스트림으로 이루어져 외부 클라우드를 전혀 거치지 않습니다.
- **접속 장치 관리**: 호스트 PC 화면에서 현재 연결된 모든 클라이언트를 실시간으로 확인하고 불필요한 기기를 즉각 차단할 수 있습니다.

---

## 사용 방법

1. EQT 데스크톱 프로그램에서 "Chat" 탭을 클릭합니다.
2. 화면에 표시된 QR 코드나 URL 주소를 참여자들에게 공유합니다.
3. 참여자가 브라우저로 접속하면 안전한 채팅 세션이 시작됩니다.
4. 호스트가 창을 닫으면 모든 통신 기록이 자동으로 완전히 파기됩니다.
