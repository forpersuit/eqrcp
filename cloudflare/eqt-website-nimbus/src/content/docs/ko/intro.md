# EQT 기술 문서 센터에 오신 것을 환영합니다

EQT(Easy QR Transfer)는 **제1원리(First Principles)**에 기반하여 설계된 크로스 플랫폼 로컬 네트워크(LAN) 초고속 직접 전송 및 실시간 협업 시스템입니다.

기존의 중앙 집중식 클라우드 스토리지나 메신저 플랫폼은 개인 사진 검열, 인공지능 모델 무단 학습 데이터 수집, 외부 업로드 대역폭 제한, 미디어 압축 등 심각한 개인정보 및 성능 문제를 내포하고 있습니다. EQT는 동일한 로컬 네트워크 내의 장치 간에 완전히 직접적이고 안전하며 초고속으로 데이터를 교환할 수 있는 환경을 제공합니다.

---

## 핵심 설계 원칙

- **물리적 회선 속도의 직접 통신 (Zero Cloud Relay)**:
  송신자와 수신자 사이에 직접 로컬 소켓을 형성합니다. 외부 클라우드 서버나 중계기를 거치지 않고 로컬 공유기나 스위치의 최대 물리적 회선 속도로 데이터를 전송합니다.
- **모바일 앱 설치 불필요 (Zero App Needed)**:
  스마트폰(iOS / Android) 사용자는 기본 카메라 앱으로 QR 코드를 스캔하기만 하면 브라우저 환경에서 즉시 파일을 주고받을 수 있습니다.
- **진정한 LAN-TLS 암호화 (WebPKI Green Lock)**:
  Let's Encrypt와 무상태 수학적 루프백 DNS를 결합하여, 로컬 네트워크 전송임에도 경고 창 없이 신뢰할 수 있는 공식 녹색 자물쇠(🔒) 보안 연결을 구현합니다.
- **메모리 기반 실시간 스트리밍 ZIP 압축**:
  수많은 파일이나 디스크 폴더 전체를 전송할 때, 임시 압축 파일을 하드디스크에 생성하지 않고 메모리 버퍼에서 실시간으로 ZIP 패킷을 구성하여 네트워크 소켓으로 밀어 넣습니다.
