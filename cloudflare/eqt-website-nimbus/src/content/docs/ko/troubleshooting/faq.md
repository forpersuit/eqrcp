# 자주 묻는 질문 (FAQ)

---

### Q1: EQT의 전송 속도는 어느 정도인가요?
**A**: 전송 처리량은 사용 중인 로컬 네트워크 장비, 무선 규격 및 기기의 저장장치 I/O 성능에 의해 전적으로 결정됩니다. **인위적인 대역폭 제한이나 클라우드 속도 제한은 전혀 없습니다.**
- **물리적 직접 링크**: EQT는 순수 P2P 로컬 소켓 스트리밍 구조를 사용합니다. 모든 데이터는 로컬 Wi-Fi 또는 유선 네트워크 안에서만 이동하며 외부 클라우드 병목 현상이 발생하지 않습니다.
- **하드웨어 한계치 포화**: 실제 속도는 장치의 Wi-Fi 규격(Wi-Fi 5 / Wi-Fi 6 / Wi-Fi 7), 공유기 백플레인 성능 및 플래시 스토리지(NVMe SSD / UFS 4.0)의 쓰기 속도에 맞춰지며, EQT 엔진은 물리 회선의 최대 대역폭을 온전히 활용하도록 설계되었습니다.

---

### Q2: 파일 전송 시 스마트폰의 모바일 데이터(LTE/5G)가 소모되나요?
**A**: **파일 본문 전송에는 모바일 데이터가 전혀 소모되지 않습니다.**
파일 데이터는 컴퓨터와 스마트폰 간에 내부 로컬 네트워크를 통해 직접 스트리밍됩니다. 초기 DNS 조회 시 전송되는 극소량의 신호(수십 바이트) 외에는 외부 통신이 일어나지 않습니다.

---

### Q3: 폴더 전체를 보낼 때 대기 시간이 없는 이유는 무엇인가요?
**A**: EQT에는 독자 개발한 **실시간 스트리밍 ZIP 엔진**이 내장되어 있습니다.
기존 도구처럼 디스크에 임시 압축 파일을 미리 생성한 후 전송하는 방식이 아니라, 파일을 읽는 동시에 메모리에서 실시간으로 압축하여 네트워크 소켓으로 밀어 넣습니다. 따라서 스마트폰에서는 접속하는 즉시 다운로드가 시작됩니다.

---

### Q4: Plus 라이선스를 새 컴퓨터로 어떻게 이전하나요?
**A**:
1. EQT 공식 셀프서비스 포털에 접속합니다.
2. 구매 시 입력한 이메일 주소를 입력하여 인증 토큰을 받습니다.
3. 기기 관리 화면에서 기존 컴퓨터 옆의 "연결 해제"를 클릭합니다.
4. 새 컴퓨터에서 EQT를 실행하고 라이선스 코드를 입력하여 활성화합니다.

---

### Q5: QR 코드를 스캔해도 브라우저가 열리지 않는 경우 어떻게 하나요?
**A**:
- **iOS**: 기본 **카메라** 앱을 사용하세요. 파일 다운로드를 제한하는 타사 메신저나 앱 내 브라우저에서의 스캔은 피해주세요.
- **Android**: 기본 카메라, Chrome 또는 Edge 브라우저를 사용하세요. 타사 앱 내에서 열린 경우 우측 상단 메뉴에서 "다른 브라우저로 열기"를 선택하세요.
