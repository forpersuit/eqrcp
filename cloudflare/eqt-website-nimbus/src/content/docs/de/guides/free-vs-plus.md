# Free vs. Plus Versionsvergleich

EQT bietet für den privaten Alltag einen vollständigen Funktionsumfang kostenlos an. Für Power-User und professionelle Arbeitsumgebungen bietet die Plus-Lizenz erweiterte Funktionen.

---

## Funktionsübersicht

| Funktion | Free-Version | Plus-Version |
| :--- | :---: | :---: |
| **Lokale Direktübertragungsgeschwindigkeit** | Volle physikalische Leitungsgeschwindigkeit | Volle physikalische Leitungsgeschwindigkeit |
| **Keine Cloud-Relays・Volle Privatsphäre** | ✅ | ✅ |
| **Keine Smartphone-App erforderlich** | ✅ | ✅ |
| **Let's Encrypt LAN-TLS 🔒** | ✅ | ✅ |
| **Ordner-Streaming als ZIP** | ✅ | ✅ |
| **Zwischenablage & Text teilen** | ✅ | ✅ |
| **Gleichzeitige Verbindungen** | Standardlimit | Unbegrenzt |
| **LAN-Kollaboration (Chat-Modus)** | Basis | Vollständig unbegrenzt |
| **Feste Portbindung & Hintergrund-Daemon** | Basisoptionen | Voll konfigurierbar |
| **Kommerzielle Nutzung** | Nur privat | Kommerzielle Lizenz enthalten |
| **Prioritärer Support** | Community | Bevorzugter E-Mail-Support |

---

## Lizenz übertragen und verwalten

Ihre Plus-Lizenz kann jederzeit über das offizielle Selbstbedienungsportal verwaltet werden.
Beim Wechsel auf einen neuen Computer trennen Sie einfach das alte Gerät im Portal und aktivieren Ihren Lizenzschlüssel auf dem neuen System.
