# Schnellstartanleitung

EQT bietet das einfachste Erlebnis für den Dateiaustausch zwischen PC und Smartphone – ganz ohne App-Installation oder Benutzerkonten.

---

## 1. Dateien senden (PC ➔ Smartphone)

1. **EQT starten**: Öffnen Sie die Anwendung unter Windows, macOS oder Linux.
2. **Dateien per Drag & Drop ablegen**:
   - Ziehen Sie die gewünschten Dateien oder Ordner direkt in das EQT-Fenster.
   - Text oder Screenshots in der Zwischenablage können ebenfalls mit einem Klick geteilt werden.
3. **QR-Code scannen**:
   - Öffnen Sie die Standard-**Kamera-App** Ihres Smartphones und richten Sie sie auf den Bildschirm.
   - Tippen Sie auf den angezeigten Link, um das Download-Portal in Safari oder Chrome zu öffnen.
4. **Alles mit einem Fingertipp laden**:
   - Ganze Ordner werden automatisch im Speicher als ZIP gebündelt und können sofort heruntergeladen werden.

---

## 2. Dateien empfangen (Smartphone ➔ PC)

1. **In den Empfangsmodus wechseln**: Wählen Sie im EQT-Hauptfenster den Reiter „Empfangen“.
2. **QR-Code scannen**: Scannen Sie den Empfangs-QR-Code mit Ihrem Smartphone.
3. **Dateien hochladen**: Wählen Sie im mobilen Browser Fotos, Videos oder Dokumente aus.
4. **Automatische Speicherung**: Die Dateien werden sofort im Downloads-Ordner Ihres Computers gespeichert.

---

## 3. Empfohlene Systemvoraussetzungen

- **Netzwerk**: Computer und Smartphone müssen mit demselben WLAN oder lokalen Netzwerk verbunden sein.
- **Browser**:
  - iOS: Standard-Safari ab iOS 14.
  - Android: Chrome, Edge oder Standard-Systembrowser.
