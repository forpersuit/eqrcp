# Bienvenue sur EQT

**EQT** est un outil de transfert de fichiers et de collaboration sur réseau local (LAN) multiplateforme, conçu selon les principes de **sécurité, confidentialité absolue et vitesse maximale au débit physique de ligne**. Il ne nécessite aucune installation d'application sur les appareils mobiles : scannez simplement un code QR avec votre appareil photo natif pour établir une liaison chiffrée directe et ultra-rapide entre votre ordinateur et vos terminaux mobiles.

---

## Avantages Techniques Clés

- ⚡ **Débit Filaire Maximal sans Étranglement** : Streaming socket direct point-à-point (P2P) en réseau local, sans relais cloud ni bridage artificiel. L'architecture matérielle sature pleinement le potentiel physique de vos équipements Wi-Fi et Ethernet.
- 🔒 **Zéro Stockage Cloud (Zéro Relais Externe)** : Vos photos, vidéos 4K, documents de travail confidentiels et échanges restent 100 % confinés dans votre réseau local domestique ou d'entreprise. Zéro octet ne transite par un serveur externe.
- 📱 **Expérience Mobile sans Friction** : Aucune application à télécharger sur iPhone, iPad ou Android. Accès direct et instantané via l'appareil photo ou le navigateur web système.
- 🛡️ **Cadenas Vert WebPKI Let's Encrypt** : Une architecture innovante de bouclage sans état LAN-TLS provisionne automatiquement des certificats dédiés via Let's Encrypt. Elle élimine définitivement les plantages mémoire (OOM) de WebKit iOS sur les gros fichiers et garantit une étanchéité cryptographique totale sans fuite de clé privée.
- 💬 **Collaboration LAN Chat Complète** : Messagerie instantanée éphémère intégrée pour synchroniser en temps réel le presse-papiers, extraits de code, jetons API et captures d'écran, avec purge totale de la mémoire RAM à la fermeture de la session.
