# EQT 竞品深度调研与差异化竞争矩阵

> **初衷与定位**：EQT (Easy QR Transfer) 定位为**面向个人与专业团队的高性能、免 App、纯物理局域网传输的独立商业数字化工具**。
> 本目录收录了主流跨端传输、局域网分享与 P2P 传输工具的深度调研与全景对比，作为产品演进、市场攻坚与 AlternativeTo 替代关系关联的权威依据。

| **EQT (本项目)** | **纯物理 LAN HTTP/2-TLS 直连** | **免装 App（原生相机扫码即传）** | **跑满物理千兆 (60~100+ MB/s)** | **自动化公网 CA 绿锁 (`*.direct.eqt.net.im`)** | **Freemium 纯净无广告 / 一次性终身买断** | 暂未上架应用商店（专注桌面+Web） |

| **Croc** | 命令行 CLI 中继 + P2P | **不支持手机 (仅限终端/CLI)** | 局域网或中继 | 自定义 PAKE 加密 | 免费开源 | 极客玩具；普通用户与移动端完全无法上手；无 GUI |
| **RetroShare** | 深度去中心化 F2F 暗网 P2P | 需安装复杂客户端 | 受 P2P 路由限制 | 强密钥指纹自加密 | 免费开源 | 极其笨重（整合邮件/论坛/聊天）；配置门槛极高；不适合快速传文件 |
| **NearDrop** | 模拟 Google Nearby Share | 仅限 Android 发送到 Mac | 局域网 Wi-Fi 直连 | Google 私有协议 | 个人开源项目 | 单向传输（无法 Mac 发送到 Android）；不支持 Windows/iOS |

## 二、EQT 的四大第一性原理降维打击优势

### 1. 移动端零门槛（Zero Friction / App-Free）
* **竞品痛点**：SHAREit、Send Anywhere、Warpinator 等工具强制要求发送端与接收端两台设备必须同时下载并安装专门的 App。临时向同事、朋友或客户传一个大文件时，对方极度抗拒安装一个几十兆、平时根本用不到的第三方 App。
* **EQT 解法**：桌面端一键生成瞬时动态二维码，**手机端原生系统相机扫码即进浏览器传输**。接收端 0 下载、0 安装、0 注册，10 秒内完成传输。

### 2. 物理千兆局域网直连，零云端泄露（Physical Gigabit LAN Speed）
* **竞品痛点**：Wormhole、Send Anywhere 等将文件先完整上传至外部云存储，再由另一端下载。跨设备明明相距 30 厘米，却要绕道几千公里公网，受限于家庭或办公宽带可怜的 30Mbps 上行速度，且存在严重的商业机密泄露隐患。
* **EQT 解法**：数据流仅在当前物理局域网（Wi-Fi / 有线 Ethernet）中端到端传输，速度跑满 60~100+ MB/s（1GB 视频只需 10~15 秒），绝不经过任何外部服务器。

### 3. 专利级免配置 LAN-TLS 权威绿锁（Zero-Config Public CA Wildcard）
* **竞品痛点**：普通局域网 Web 工具（如各种自建网页传文件）采用 HTTP 或自签名证书，在现代 iOS Safari 和 Android Chrome 中会直接触发刺眼的“不安全警告”，且因非 Secure Context 而被浏览器禁用硬件加速、流式写盘及 Clipboard API。
* **EQT 解法**：通过 `*.direct.eqt.net.im` 全自动化本地 DNS 回环与顶级权威 CA（Let's Encrypt / GTS）泛域名证书联动。手机扫码打开直接呈现“纯正绿色权威安全锁”，零配置、零根证书导入，享受现代 Web API 全速硬件加持。

### 4. 商业级终身买断制，拒绝流氓月租（Honest Freemium / Lifetime License）
* **竞品痛点**：Send Anywhere 充斥大量恶心全屏弹窗广告并强制推销每月 5.99 美元的流氓月租；而完全无商业模式的开源玩具往往因为没有服务器与证书维护成本而面临停更或信令节点失效。
* **EQT 解法**：日常核心功能永久免费无广告；高阶多网卡智能分流、局域网权威 TLS 自动维持采用一次性合理终身买断（Lifetime License），商业契约透明，可持续维护。
