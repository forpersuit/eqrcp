  二、激活码激活流程 — 文案语言审计

  调用链:main.js confirmRedeem() → ActivateLicense() → agent.go:1126 → pkg/server/license.go:236 ActivateLicenseOnline → POST
  lic.eqt.net.im/api/v1/activate → Cloudflare Worker drm.ts → 校验 → Ed25519 签名 → 本地写 license.lic。

  🔴 关键问题 1:服务端 7 语字典形同虚设,激活错误永远英文

  服务端 /activate 的错误消息其实支持 7 语字典(cloudflare/eqt-drm-api/src/i18n.ts API_I18N,语言由 body.lang 或 Accept-Language
  决定)——但这套机制根本没被接通:

  - 桌面调用的是 ActivateLicenseOnline(code) → ActivateLicenseOnlineWithLang(licenseCode, ""),lang 永远传空串(license.go:236)。
  - ActivateLicenseOnlineWithLang 的 lang 参数从未被真正接入(仅 agent.go:1126、cmd/desktop_agent.go:805 两处,都走空 lang 的重载)。
  - 服务端 extractRequestLang 收不到 lang → 默认 "en"。

  结果:中文界面的用户激活失败时,服务端返回的 7 语错误(如"该授权码已超过有效期")实际以英文返回(License has expired 等)。i18n
  基础设施齐全但接线断了。
