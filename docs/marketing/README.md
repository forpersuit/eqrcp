## 🧭 营销执行第一性原则

* **以欧美及全球非中文市场为主**：中文负责底层思考与痛点解构，海外物料 100% 采用地道自然的英文及当地语种表达，贴合真实的海外工作生活痛点。
* **零外链发推原则**：X (Twitter) 主贴一律不带外部链接，通过评论区第 1 条（First Reply）沉淀官网与下载链接，避免算法降权。
* **动图与视频驱动**：文字建立信任，动图抓住眼球。所有推文与海外社区发帖优先搭配 5~7 秒极简演示动图（拖拽文件 -> 手机自带相机扫码 -> 满速下载）。
* **透明与真诚**：不搞大厂虚标、不端架子。清晰讲明纯局域网的边界、日常免费的良心与专业买断的契约。
