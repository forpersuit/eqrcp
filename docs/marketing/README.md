## 🧭 营销执行第一性原则

* **零外链发推原则**：主贴内容一律不添加外链，通过评论区第 1 条（First Reply）与置顶回复沉淀 GitHub 仓库与官网链接，避免算法降权。
* **注重隐私与本地极速**：在所有海外营销物料中，始终突出“100% 局域网传输，数据 0 上传云端”与“手机端免装 App 扫码即用”的独特差异化卖点。
* **高质感视觉驱动**：技术类推文与 Reddit/HN 发帖优先搭配清晰的终端 QR 码与手机扫码交互 GIF 动图，提升直观认知。
