# EQT (Easy QR Transfer) — 核心功能短视频与动态视觉推广计划 (Short Video & Motion Campaign)

在 Twitter (X)、TikTok、YouTube Shorts、Bilibili 与微信视频号等平台上，纯文字/静态图的转化率往往受限，而“**终端生成二维码 -> 手机秒扫直连 -> 80MB/s 进度条极速飙升 -> 跨端即时 Chat 剪贴板同步**”具有极强的**视觉爽感与即时冲击力**。

本文档规划了 EQT 核心功能短视频矩阵、15~30 秒高转化分镜头脚本、拍摄演示 SOP 与转化链路。

---

## 1. 短视频推广定位与视觉爽点 (Core Visual Hooks)

短视频的核心在于 **前 3 秒抓住眼球（Hook）**，**中间 15 秒展示极简交互与性能狂飙（Demo）**，**后 5 秒引导行动（CTA）**。

| 视频定位 | 核心功能点 | 目标受众 | 视觉爽点 (Visual "Aha!" Moment) |
| :--- | :--- | :--- | :--- |
| **视频 1: 痛点直击型** | 扫码免装 App 极速传文件 | 全体跨设备办公族、极客 | 扔掉数据线与微信，终端一敲扫码即传 |
| **视频 2: 多设备并发型** | Receive & Share 多端并发 | 办公室团队、聚会好友、家庭 | 1 台电脑屏幕，4 部不同品牌手机同时扫码并发下载 |
| **视频 3: 极客私密 Chat 型** | Chat 局域网即时加密聊天 | 程序员、DevOps、注重隐私者 | 电脑敲代码/Token，手机端秒级同步，会话关闭即焚 |
| **视频 4: 硬核性能狂飙型** | 跑满局域网千兆物理带宽 | 视频剪辑师、摄影师、大文件玩家 | 20GB 4K 素材在 80MB/s 速度下进度条飞速拉满 |

## 3. 短视频发布平台与运营转化规范

### 3.1 平台分发矩阵
1. **Twitter (X) Video**：
   - 视频时长控制在 20 秒以内，画面比例 16:9（桌面端极客友好）或 9:16（移动端全屏）。
   - 视频内置大字硬字幕（很多 Twitter 用户静音刷推）。
   - 主推文不加链接，评论区第 1 条置顶 GitHub 仓库与官网。
2. **TikTok / YouTube Shorts / 微信视频号 / B站 Shorts**：
   - 采用 9:16 坚屏实拍/录屏，配轻快科技 BGM。
   - 简介引导：“项目已开源，获取方式见置顶评论”。

### 3.2 视频制作技术规范
* **录屏工具**：OBS Studio (电脑端 60fps 无损录制) + iOS/Android 内置无损录屏。
* **分屏展示**：使用双拼分屏（左侧电脑终端/GUI，右侧手机屏幕实操录屏），中间用动态箭头展示数据流向。
* **字幕设计**：粗体黄色/白色高对比度无衬线字体，关键词（如“免装App”、“80MB/s”、“完全开源”、“局域网直连”）加红色/绿色高亮。
