# Frontend Domain Invariants (前端就近层规范)

> **上级索引**：本文件继承根目录 `AGENTS.md` 的所有元层公理与全局反射。此处定义前端作用域下的绝对硬不变量。

---

## 1. 表现层零业务逻辑 (No Business Logic in Rendering)
- **核心定位**：组件、模板与渲染函数仅充当纯值映射（`Data -> DOM`），严禁在前端进行业务决策。
- **判别三问**：
  1. 第二客户端（如 CLI/移动端）是否需要重写这段逻辑？
  2. 产品经理是否会把它写进需求文档？
  3. 写错的后果是显示难看，还是业务状态/金额/权限错误？
  凡符合其一，必须由后端计算语义化纯值并下发（如 `canEdit: bool`, `status: "overdue"`）。
- **允许的展示逻辑**：
  - 纯函数格式化：时间格式化、字节大小换算（`formatBytes`）、国际化翻译。
  - 语义枚举映射到样式 class：`severity: "critical"` -> 红色类名。
  - 基于 ViewModel 布尔值的显隐判断：`{#if vm.canEdit}`。
- **严厉禁止**：
  - 在模板/组件内使用比较运算符（`==`, `!=`, `>`, `<`, `>=`, `<=`）做业务逻辑判断。
  - 在模板内做算术运算或多字段状态派生（`a && b || c`）。

---

## 2. 状态与渲染分离 (State-Template Separation)
- **纯函数渲染**：以 `render` 开头的渲染模板纯函数中，**严禁直接修改全局 `state` 的值**。
- **单向调度**：状态修改必须由明确的 Controller 方法或事件处理函数统一调度，渲染函数只充当 `Data -> DOM` 的只读投影。

---

## 3. 标准声明式事件绑定 (Declarative Event Listeners)
- **绝对禁止内联事件**：严禁在 HTML 字符串中拼接全局内联 `onclick="..."` 事件！
- **标准监听器**：所有事件应当使用标准 `addEventListener` 进行注册与生命周期管理，防止全局作用域污染与内存泄露。

---

## 4. 模块化防膨胀 (Modularity & Separation of Concerns)
- **单文件行数控制**：禁止向 `main.js` 无限堆砌新的功能代码。
- **组件拆分**：任何独立的业务交互、多语言字典、大型渲染块，必须剥离到 `src/` 下的子模块中维护。
